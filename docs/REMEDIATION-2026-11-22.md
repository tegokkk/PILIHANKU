# Hasil perbaikan temuan production

22 November 2026. Perubahan lokal pada PILIHANKU; deployment dilakukan manual oleh pemilik proyek. Tidak membuat paket deployment atau mengubah data production. Pengujian menggunakan database/proses PostgreSQL terpisah dan data sintetis. Sumber sebelum perubahan disimpan di `backend/.local/release-before-20261122/`, tanpa `.env`.

## Verifikasi akhir

- Backend **41/41 lulus, nol skip/gagal**, termasuk integrasi, operasi, outage/restart dan backup/restore; `output/qa/release/backend-tests-final.log`. Alat PostgreSQL diberikan melalui PG_BIN. Percobaan awal yang timeout tidak dihitung sebagai lulus; hasil terakhir diperoleh sesudah memperbaiki penghentian cluster test Windows.
- Frontend **13/13 lulus**, kedua ESLint lulus, format diperiksa, build Vite production berhasil. Entry sekitar 578,48 KB / 194,83 KB gzip; PDF tetap dynamic import, cache publik tidak mencakup API.
- Browser memakai akun sintetis siswa/BK/superadmin. Halaman publik, empat langkah, konsultasi dan pengelolaan diperiksa pada 1280 dan/atau 360 CSS px sesuai setiap rekaman. Tidak ada overflow horizontal halaman pada pengukuran tersimpan. Ini bukan klaim semua state pada semua ukuran.
- `accessibility-all-scans.json` menyimpan seluruh 31 scan termasuk hasil awal/transisi. Label span diperbaiki, role group diuji ulang; scan kontras pada transisi login yang awalnya gagal juga disimpan. Hasil final untuk state terkait tidak memiliki violation. Daftar scan yang menggantikan hasil awal tersedia pada `accessibility-summary.json`; `incomplete` tetap memerlukan pertimbangan, bukan sertifikasi WCAG.
- Beranda development `localhost:5173` diperiksa kembali; console error/warning untuk origin itu kosong pada pemeriksaan akhir. Screenshot `home-final.jpg`. Override viewport/media sementara telah dibersihkan. Uji ini tidak mengaktifkan Mode Tamu atau membuka fitur siswa sebelum login approved.
